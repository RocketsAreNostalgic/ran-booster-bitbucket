# Security

Only the latest Beta release receives security fixes.

Report vulnerabilities through GitHub's private vulnerability-reporting form:

https://github.com/RocketsAreNostalgic/ran-booster-bitbucket/security/advisories/new

If that form is unavailable, open a public issue containing only a request for
confidential contact. Do not include vulnerability details, provider
credentials, webhook secrets, WordPress salts, database contents, signed URLs,
release assets, customer data, or production log extracts in a public issue.

Include the RAN Booster Bitbucket Cloud, RAN Booster, WordPress, and PHP
versions in the private report. Describe whether the affected repository is
public or private, but redact its identity when disclosure is not necessary to
reproduce the problem.
